# The Dame Bean

The Bean is Dame Coffee's quiet guide—not wallpaper. Each appearance should help explain a state, celebrate a moment, or add a timely seasonal detail.

## State library

| File | Use |
| --- | --- |
| `bean-walking.png` | Route loading and moving between moments |
| `bean-sleeping.png` | Closed or paused ordering |
| `bean-confused.png` | 404, offline, or searching states |
| `bean-sold-out.png` | Sold-out menu details |
| `bean-celebrating.png` | Order success and pickup completion |
| `bean-driving.png` | Catering request confirmation |
| `bean-rewards.png` | Points progress and reward milestones |
| `bean-pouring.png` | Preparing orders and daily prep |
| `bean-spring.png` | March through May |
| `bean-summer.png` | June through August |
| `bean-autumn.png` | September and November |
| `bean-halloween.png` | October |
| `bean-winter.png` | December through February |

## Visual rules

- Preserve the tall bean silhouette, center seam, long nose, and tiny puckered mouth.
- Use warm burgundy linework, white fills, and the original hand-drawn imperfection.
- Use the softer closed-eye Bean for calm moments and the expressive eyebrow Bean for playful feedback.
- Keep props simple and immediately readable.
- Never add the Bean only to fill empty space.
- Use one primary Bean moment per screen.
- Keep seasonal cameos small unless the season is the page's actual subject.
- Always provide meaningful alternative text unless the image is decorative.

## Production notes

These PNG assets were generated with OpenAI's built-in image generation using the original Dame Bean artwork as a visual reference. Each pose was generated on a flat chroma background, converted to a transparent PNG, and visually checked before use.
